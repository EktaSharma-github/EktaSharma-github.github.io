## Local preview

This is a static site. Open `index.html` directly, or serve the folder with any static HTTP server.

For example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

This repository is named `EktaSharma-github.github.io`, which makes it the user-level GitHub Pages repository for the `EktaSharma-github` account.

In **Settings → Pages**, select **Deploy from a branch**, choose `main`, and select the repository root (`/`) as the publishing folder.

The expected public site is:

**https://ektasharma-github.github.io/**
