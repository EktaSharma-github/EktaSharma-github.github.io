Which two-paper combinations are closest?

An interactive visual explorer built from the GATE 2027 two-paper-combination table. Use the network, degree chart, clusters and matrix to understand which papers share the most permitted secondary-paper relationships.

Click a node to highlight its neighbours.

1 · Combination network

Each node is a GATE paper. A line means the paper is allowed as the secondary paper for the other paper. Node size = number of permitted connections.

Tip: select a paper above or click a node. The chart and matrix are designed for comparing structural options—not for predicting admission, rank or score.

2 · Domain clusters

A practical grouping to make the network easier to reason about. Cluster membership is interpretive; the official combination rules remain the source of truth.

3 · Pairwise matrix

Rows are primary papers; columns are secondary papers. Green cells indicate an allowed pairing. Use it to spot dense regions and asymmetric-looking choices.
