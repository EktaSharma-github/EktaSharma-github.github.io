# GATE 2027 Two-Paper Combination Explorer

Interactive visualization of the GATE 2027 two-paper combination table supplied from IIT Madras.

## Views
- Network graph: papers as nodes and permitted combinations as links.
- Degree chart: identifies highly connected primary papers.
- Domain clusters: groups papers for easier visual analysis.
- Pairwise matrix: primary-vs-secondary relationship map.
- Search/focus controls: isolate a paper and its neighbours.

## Data interpretation
The network uses the supplied table as a directed primary → secondary relationship, while the visual network collapses reciprocal entries into unique undirected relationships for readability. The matrix preserves the original direction.

This is an analysis/visualization aid, not an admissions predictor. Candidates should verify the final combination list on the official GATE 2027 website before registration.

## Files
- `gate-2027.html` — standalone interactive page.
- `gate-2027-data.js` — source data object transcribed from the supplied table.
